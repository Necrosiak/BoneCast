# BoneCast 🦴📡

**Twitch and YouTube in Steam Gaming Mode**: a free, open-source
[Decky Loader](https://github.com/SteamDeckHomebrew/decky-loader) plugin for
Steam Deck, Bazzite, SteamOS and other Linux systems.

Go live on Twitch or YouTube from the Steam Quick Access Menu, with a chat
overlay over your game, a pause screen, local recording and more.

- Source code, install guide and documentation:
  [github.com/Necrosiak/BoneCast](https://github.com/Necrosiak/BoneCast)
- Report a problem or suggest an idea:
